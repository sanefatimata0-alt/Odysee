✈️ Odysée — Agence de voyages

«Voyagez plus loin. Vivez plus fort.»

Odysée est un site web vitrine conçu pour une agence spécialisée dans l'organisation de voyages personnalisés.

Le projet présente une expérience simple, moderne et chaleureuse permettant aux visiteurs de découvrir des destinations, consulter des guides de voyage et obtenir des informations sur les services proposés.

---

🌍 Présentation

Odysée accompagne les voyageurs dans la création de voyages adaptés à leurs envies, leur rythme et leur budget.

Le site met en avant plusieurs destinations comme :

- 🇯🇵 Kyoto — Japon
- 🇿🇦 Le Cap — Afrique du Sud
- 🇮🇸 Reykjavik — Islande

L'objectif est de proposer une interface esthétique et facile à utiliser tout en mettant en pratique les notions de développement web étudiées.

📱 Responsive Design

Le site utilise des Media Queries CSS afin d'adapter automatiquement l'affichage aux petits écrans.

Deux principaux points de rupture sont utilisés :

@media (max-width: 800px)

et

@media (max-width: 430px)

Sur mobile :

- le menu devient un bouton ☰ ;
- les cartes passent en une seule colonne ;
- les sections sont réorganisées ;
- les images sont redimensionnées ;
- le footer devient vertical.

❤️ Système de favoris

Chaque destination possède un bouton cœur.

Lorsque l'utilisateur clique dessus :

♡ → ♥

La couleur du cœur change également pour indiquer que la destination a été ajoutée aux favoris.

Un deuxième clic permet de retirer le favori :

♥ → ♡

🚀 Installation

Aucune installation particulière n'est nécessaire.

1. Cloner le projet

git clone https://github.com/sanefatimata0-alt/Odysee.git

2. Ouvrir le dossier

cd Odysée

3. Lancer le site

Ouvrir simplement le fichier :

index.html

dans un navigateur.

Vous pouvez également utiliser Visual Studio Code avec l'extension Live Server.
